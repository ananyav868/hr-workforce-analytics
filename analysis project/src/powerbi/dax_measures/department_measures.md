# DAX Measures: Department Insights

Power BI DAX measure definitions for the Department Insights scorecard page. These measures reference the star schema tables: `fact_employee_metrics`, `dim_department`, `dim_employee`, and `dim_date`.

> **Validates: Requirements 8.1, 8.3**

---

## 1. Department Headcount

**Measure Name:** `Department Headcount`

**Description:** Calculates the total headcount for the selected department. Sums the headcount column from the fact table within the current department filter context. When used on the department scorecard, it reflects the active workforce size.

**Intended Visual:** KPI card on the Department Insights scorecard page.

```dax
Department Headcount =
SUM( fact_employee_metrics[headcount] )
```

> **Usage Note:** This measure evaluates within the department filter context set by Row-Level Security or a department slicer. Place on a KPI card or scorecard visual for the department insights page.

---

## 2. Department Attrition Rate

**Measure Name:** `Dept Attrition Rate %`

**Description:** Calculates the attrition rate for the selected department as a percentage. Defined as the number of employees who departed divided by the total headcount, multiplied by 100. Evaluates within the current department filter context.

**Intended Visual:** KPI card on the Department Insights scorecard page.

```dax
Dept Attrition Rate % =
VAR _Departures =
    CALCULATE(
        COUNTROWS( fact_employee_metrics ),
        fact_employee_metrics[attrition_flag] = TRUE()
    )
VAR _TotalHeadcount =
    SUM( fact_employee_metrics[headcount] )
RETURN
    IF(
        _TotalHeadcount = 0,
        BLANK(),
        DIVIDE( _Departures, _TotalHeadcount ) * 100
    )
```

> **Usage Note:** When Row-Level Security filters the department context, this measure automatically scopes to the manager's department. Format as percentage with one decimal place.

---

## 3. Average Tenure

**Measure Name:** `Avg Tenure (Months)`

**Description:** Calculates the average tenure in months for all employees in the selected department. Uses the `tenure_months` column from the fact table.

**Intended Visual:** KPI card on the Department Insights scorecard page.

```dax
Avg Tenure (Months) =
AVERAGE( fact_employee_metrics[tenure_months] )
```

> **Usage Note:** Display on the scorecard with a subtitle indicating "months". Consider conditional formatting to highlight departments with unusually low average tenure (potential retention concern).

---

## 4. Average Satisfaction Score

**Measure Name:** `Avg Satisfaction Score`

**Description:** Calculates the average employee satisfaction score for the selected department. Uses the `satisfaction_score` column from the fact table, which typically ranges from 1.0 to 5.0.

**Intended Visual:** KPI card on the Department Insights scorecard page.

```dax
Avg Satisfaction Score =
AVERAGE( fact_employee_metrics[satisfaction_score] )
```

> **Usage Note:** Format to two decimal places. Use conditional formatting with thresholds (e.g., green ≥ 4.0, yellow 3.0–3.9, red < 3.0) to provide at-a-glance health indication.

---

## 5. Open Positions

**Measure Name:** `Open Positions`

**Description:** Estimates the number of open positions for the selected department by counting employees who have departed (attrition_flag = TRUE) within the current reporting period. This serves as a proxy for unfilled roles derived from attrition data.

**Intended Visual:** KPI card on the Department Insights scorecard page.

```dax
Open Positions =
CALCULATE(
    COUNTROWS( fact_employee_metrics ),
    fact_employee_metrics[attrition_flag] = TRUE()
)
```

> **Usage Note:** This measure derives open positions from attrition events in the selected time period. For more accurate tracking, an external requisition data source could replace this proxy. Use a date slicer to scope to the current quarter or month.

---

## 6. Predicted Attrition Risk

**Measure Name:** `Predicted Attrition Risk`

**Description:** Calculates the average predicted attrition probability from the ML model, aggregated at the department level. The `attrition_probability` column contains per-employee predictions generated by the trained model (values between 0 and 1). This measure averages those probabilities across all employees in the selected department to provide an overall department risk score.

**Intended Visual:** KPI card on the Department Insights scorecard page; also used as a gauge visual showing department-level risk.

```dax
Predicted Attrition Risk =
AVERAGE( fact_employee_metrics[attrition_probability] )
```

> **Usage Note:** Format as a percentage (0–100%). Use conditional formatting with risk thresholds (e.g., green < 15%, yellow 15%–30%, red > 30%) to flag high-risk departments. This measure supports drill-through to individual employee risk profiles (Requirement 8.4).

---

## Usage Instructions

1. Open Power BI Desktop and connect to the star schema database.
2. Navigate to the **Modeling** tab → **New Measure**.
3. Paste each DAX formula above into the formula bar.
4. Assign measures to the Department Insights scorecard page as described.

### Scorecard Layout

Arrange the six KPI cards in a 2×3 or 3×2 grid at the top of the Department Insights page:

| Row 1 | Row 2 |
|--------|--------|
| Department Headcount | Avg Tenure (Months) |
| Dept Attrition Rate % | Avg Satisfaction Score |
| Open Positions | Predicted Attrition Risk |

Each card should include a trend sparkline showing the last 12 months of data (Requirement 8.5).

### Slicer Compatibility

All measures respond to the following slicers (cross-filter):
- **Date Range** — filters `dim_date` to constrain the time period
- **Department** — filters `dim_department[department_name]` (auto-set by RLS for managers)

### Relationships Required

Ensure the Power BI data model has active relationships:
- `fact_employee_metrics[department_key]` → `dim_department[department_key]`
- `fact_employee_metrics[employee_key]` → `dim_employee[employee_key]`
- `fact_employee_metrics[date_key]` → `dim_date[date_key]`

### Row-Level Security Integration

When a user with the `Department_Manager` role opens this page, the RLS filter on `dim_department` automatically scopes all measures to the manager's assigned department. HR Executives see an aggregated view or can select departments via slicer. See `src/powerbi/security/rls_config.md` for RLS configuration details.

### Drill-Through Configuration

The department scorecard supports drill-through to an **Employee Risk Profile** detail page. Users can right-click on the Predicted Attrition Risk KPI or any employee row to navigate to individual employee details showing:
- Predicted attrition probability
- Top contributing factors (from feature importance)
- Historical trend of risk score
